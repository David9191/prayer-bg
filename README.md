# 주기도문 배틀그라운드

중고등부 LOOK 활동(마태복음 6:9–13, 소요리문답 99–107문)용 3D 웹 게임. 배틀그라운드를 모티브로, 주기도문 조각 8개를 **순서대로** 모아 '아멘'을 외치면 클리어.

- 플레이: `index.html` (QR로 접속)
- 관리자: `admin.html` (비밀번호 필요) — 대기실 열기·게임 시작/종료·실시간 순위·지도·통계
- 기술: Three.js r170 + Firebase Realtime Database (익명 로그인)

## 사용한 무료 자료 (모두 CC0, 표기 의무 없음)
- 텍스처·하늘·3D 모델: [Poly Haven](https://polyhaven.com) (island_tree_02, pine_sapling_small, shrub_02, grass_medium_01, quiver_tree_02, covered_car 등)
- 효과음: Kenney Impact Sounds
- 배경음악: "Determined Pursuit (epic orchestra loop)" by Emma_MA (OpenGameArt)
- 병사 모델: three.js 예제 Soldier.glb (Mixamo 애니메이션)
